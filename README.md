Entry for the make.fun bounty **"One Line of Earned Pride"**:
https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557

The entry is a single line about a night janitor who taught himself to
read from the posters in the classrooms he cleaned — and who this
morning signed his daughter's report card without asking anyone to
read it first. The pride is never named; it is earned inside the
scene, in the effort and in the small act that lands it.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# writes out/entry.txt — the one line, 1–240 characters, UTF-8
```

`main.py` (Python 3, standard library only) validates the line against
the bounty's gate (1–240 characters, not only white space) and writes it
to `entry.txt` in the output directory.
